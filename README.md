### Yêu cầu hệ thống:
- Python 3.9+
- Pip (Python Package Installer)

### Cài đặt:
1. Clone mã nguồn về máy:
   ```bash
   git clone https://github.com/cuongalse-coder/tinnam888888.git
   cd tinnam888888
   ```

2. Cài đặt các thư viện cần thiết:
   ```bash
   pip install -r requirements.txt
   ```
   *(Đảm bảo đã cài đặt `streamlit`, `pandas`, `numpy`, `scikit-learn`, `requests`, `beautifulsoup4`)*

3. Khởi chạy Giao diện Oracle:
   ```bash
   streamlit run streamlit_app.py
   ```

4. Truy cập ứng dụng tại: `http://localhost:8501`
5. **Mật khẩu truy cập hệ thống:** `1991`
